# Painel de Tráfego — Setembro 2026

Uso interno · Grupo SOU.

O painel é uma página estática, servida por um endereço próprio. Use o link que você recebeu.

## Estrutura

- `index.html` — página neutra na raiz
- `<endereço>/index.html` — o painel
- `robots.txt` — bloqueia indexação por buscadores

## Atualização

O painel é um retrato do momento em que foi gerado — o carimbo no topo diz a hora exata.
Para atualizar, as consultas são refeitas nos bancos e o `index.html` do painel é regravado.
